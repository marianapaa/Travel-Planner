# Travel-Planner
Travel Planner is an interactive web application for discovering and organizing travel destinations. Developed by a team of Erasmus+ students as a final project for the "Problem Solving" course.
## Features

- Search for cities using OpenStreetMap Nominatim API
- Discover nearby attractions with Geoapify Places API
- Interactive maps powered by Leaflet and OpenStreetMap
- Create and manage a personal trip list
- Add custom locations manually
- Filter results by category
- Sort places by distance
- View descriptions and images from Wikipedia
- LocalStorage caching for faster repeated searches
- Built-in unit tests for core functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Geoapify Places API
- OpenStreetMap Nominatim API
- Wikipedia API
- Leaflet.js
- LocalStorage
